Texas Hold'em Game Platform Source Code

Unity/C# clients, a C++ server and MySQL/Redis with a lobby, clubs, leagues, private friend games, tournaments and multiple variants.

Club members and management, multi-club leagues, private rooms, friend invitations, multiplayer tables, results, hand history, insurance, gifts, bots, voice/video and administration.
