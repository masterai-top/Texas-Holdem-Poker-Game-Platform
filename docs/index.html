德州扑克俱乐部与私人局游戏平台

多人实时德州扑克产品，包含大厅、俱乐部、联盟、好友局、私人桌、锦标赛、运营工具和多种玩法，采用 Unity 客户端与 C++ 服务端。

产品功能

俱乐部与联盟

创建/加入、成员、代理、俱乐部管理、内部牌局与多俱乐部联盟。

私人局与好友局

创建私人房、好友邀请、2-6人桌、2-9人桌、玩家资料与牌谱。

赛事与运营

MTT、SNG、战绩、保险、礼物、机器人、语音视频和后台管理。

游戏玩法

经典德州、AOF、6+短牌、奥马哈、大菠萝、MTT、SNG及德州牛仔。

技术架构

Unity/C# iOS与Android客户端，C++游戏/房间/消息服务，MySQL + Redis数据层和多人实时状态同步。
