# 德州扑克游戏平台｜德州俱乐部、私人局、联盟与好友局源码

以线上 README 为基础整理的多人多玩法德州扑克平台：Unity/C# 客户端、C++ 服务端、MySQL + Redis，包含大厅、俱乐部、联盟、私人局/好友局、代理、MTT、SNG、AOF、短牌、奥马哈、大菠萝、战绩、保险、语音视频、礼物、机器人和后台管理。

> 线上运营年限、稳定性与并发能力属于项目方说明，使用前应以代码、数据库、部署文档和基准测试独立核验。
