# Texas Hold'em Game Platform Source Code｜Clubs, Leagues and Private Friend Games
Based on the existing online README: Unity/C# clients, a C++ server and MySQL/Redis with clubs, leagues, private games, friend games, MTT, SNG, AOF, Short Deck, Omaha, Pineapple, records, insurance, voice/video, gifts, bots and administration.
