This is a multiplayer Texas Hold’em poker game platform system.

## 🚀 Why Choose This Project



- Complete Texas Hold'em poker system
- Multiplayer real-time gameplay
- Club + agent system included
- Ready for deployment & customization

gameroot.cpp/h # Game room management

## 🚀 Tech Stack


- **Client**: Unity (C#) - Supports iOS/Android
- **Server**: C++ - High-performance, stable operation
- **Database**: MySQL + Redis
