# 德州撲克遊戲平台源碼｜俱樂部、聯盟、私人局與好友局
多人即時德州撲克平台，包含 **Unity/C# 用戶端、C++ 伺服器、MySQL、Redis**，涵蓋大廳、俱樂部、聯盟、私人局/好友局、代理、錦標賽、多種玩法及營運後台。

## 產品功能
- 大廳、房間列表、快速遊戲及多人牌桌。
- 建立/加入俱樂部、成員管理、俱樂部詳情及內部牌局。
- 多俱樂部聯盟、大聯盟模式、代理與後台管理。
- 私人房、好友約局、邀請、2-6 人桌及 2-9 人桌。
- 戰績、牌譜、玩家資料、保險、禮物、機器人、語音及視訊。

## 遊戲玩法
經典德州、AOF、6+短牌、奧馬哈、大鳳梨、MTT、SNG及德州牛仔。

## 技術架構
Unity/C# iOS、Android 用戶端；C++ 遊戲服務、房間及訊息處理；MySQL + Redis 資料層。
