# 德州撲克遊戲平台｜德州俱樂部、私人局、聯盟與好友局源碼
本專案沿用線上 README 的多人多玩法產品內容：Unity/C# 用戶端、C++ 伺服器、MySQL + Redis，包含大廳、俱樂部、聯盟、私人局/好友局、代理、MTT、SNG、AOF、短牌、奧馬哈、大鳳梨、戰績、保險、語音視訊、禮物、機器人及後台管理。
